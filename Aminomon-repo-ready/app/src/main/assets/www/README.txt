AMINOMON - web version (works offline once opened)

HOST IT (free, 2 minutes)
  Upload this whole folder to any static HTTPS host, e.g.
  - Netlify Drop (app.netlify.com/drop): drag the folder in
  - Cloudflare Pages or GitHub Pages
  The page must be served over https (a localhost test server also works).

INSTALL ON ANDROID
  Open the link in Chrome, wait for the menu to appear, then
  Chrome menu > "Install app" / "Add to Home screen".
  After the first load it starts without internet.

NOTES
  - Landscape works best (80x24 characters minimum).
  - The first visit reloads the page once by itself (it sets up offline mode).
  - Progress is stored in the browser. Menu (top right) > "Back up save" saves a file.
  - Opening index.html straight from the file system does NOT work (browsers block it).
